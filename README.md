# RoadMap-Generator-V1

# An AI-powered tool to craft personalized technical roadmaps for any skill imaginable.

## Features

- Generate comprehensive learning paths.
- Leverage Gemini Pro PI for AI-driven content.
- Visualize roadmaps with GraphViz.

## How It Works

- Enter the field name.
- Generate a complete learning path.
- Visualize the roadmap.

## Tools and Technologies

- Python
- Gemini Pro PI
- GraphViz
